예시 데이터 → 구글 시트용 CSV

아래 파일을 내려받아 구글 시트의 각 워크시트에 파일 › 가져오기 › 업로드로 넣으면 바로 운영 데이터로 쓸 수 있습니다.

  1. 구글 시트 새 문서를 만들고, 하단 탭 이름을 파일 이름과 똑같이 지정합니다.
  2. 각 탭에서 파일 › 가져오기 › 업로드 → 해당 CSV 선택 → 현재 시트 바꾸기.
  3. 문서를 공유 › 링크가 있는 모든 사용자(뷰어)로 바꿉니다.
  4. 주소창의 /d/ 와 /edit 사이 문자열을 js/config.js 의 sheetId 에 넣고, dataSource 를 'sheets' 로 바꿉니다.
